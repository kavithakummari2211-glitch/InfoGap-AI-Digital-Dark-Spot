# InfoGap AI – Digital Dark Spot

**AI-Assisted Information Gap Detection Platform**

## About the Project
InfoGap AI is a web-based project designed to help users identify missing, conflicting, unclear, and potentially outdated information across multiple online sources.

## Problem Statement
Online information is scattered across websites and documents. Users may find conflicting claims, outdated details, and unanswered questions. Ordinary search tools may not clearly identify what information is missing or needs verification.

## Proposed Solution
InfoGap AI aims to analyze information from different sources, highlight potential information gaps, identify possible contradictions, and guide users on what they should verify next.

## Key Features
- Research question input
- Source information collection
- Potential information gap identification
- Possible contradiction detection
- Outdated information warnings when source dates are available
- Verification checklist
- Source references and evidence transparency

## Technologies Used
- Python
- HTML
- Other dependencies listed in requirements.txt

## Project Files
- app.py – Python application
- index.html – Web interface
- requirements.txt – Required Python packages

## How to Run
Install the dependencies:

pip install -r requirements.txt

Run the Python application:

python app.py
